Installing kubectl on Ubuntu is straightforward. The recommended and most secure method is using the official Kubernetes APT repository, as it ensures you get the latest stable version and automatic updates.
Here is the step-by-step guide to installing it via APT.
Step 1: Update the package index and install prerequisites
First, ensure your package manager is up to date and that you have the necessary tools to download packages over HTTPS.
Bash
sudo apt-get update
sudo apt-get install -y apt-transport-https ca-certificates curl gnupg
Step 2: Download the public signing key
Download the public signing key for the Kubernetes package repositories. This ensures the authenticity of the software you are downloading.
Bash
# Create the directory for the key if it doesn't exist
sudo mkdir -p -m 755 /etc/apt/keyrings

# Download the key
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.31/deb/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg
sudo chmod 644 /etc/apt/keyrings/kubernetes-apt-keyring.gpg
Note: If you want a specific Kubernetes version other than v1.31, replace v1.31 in the URL above with your desired version (e.g., v1.30).
Step 3: Add the Kubernetes APT repository
Next, add the repository to your system's sources list so apt knows where to find the kubectl package.
Bash
echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.31/deb/ /' | sudo tee /etc/apt/sources.list.p/kubernetes.list
sudo chmod 644 /etc/apt/sources.list.d/kubernetes.list
Step 4: Install kubectl
Update your package index one last time to include the new repository, then install kubectl.
Bash
sudo apt-get update
sudo apt-get install -y kubectl
Step 5: Verify the Installation
To confirm that kubectl was installed successfully and check the version, run:
Bash
kubectl version --client --output=yaml
Alternative: Quick Install via Snap
If you are working in a personal or development environment and prefer a single-command setup, you can use Ubuntu's built-in snap package manager:
Bash
sudo snap install kubectl --classic
